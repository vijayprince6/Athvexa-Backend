# 🏆 Athvexa Frontend
Modern Sports Social Platform (React + Firebase Hosting)

A responsive single-page application for athletes and coaches featuring rankings, achievement verification, chat system, and certificate-based profiles.

---

## 🚀 Features

- 🏅 Athlete rankings & leaderboards
- 💬 Real-time chat system
- 📸 Certificate-based achievement uploads
- 👤 Athlete & coach profiles
- 🏟️ Sports-based categorization
- 🔐 JWT authentication system
- 📱 Fully responsive UI

---

## ⚙️ Tech Stack

- React.js
- React Router
- Firebase Hosting
- Axios
- JWT Authentication
- Cloudinary (media storage)
